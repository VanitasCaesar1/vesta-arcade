# Microservices

Fifteen tiny developer jobs, a few seconds each, in a random order:

center the div · exit vim · reject the cookies · close the brackets · kill the runaway process · find the missing semicolon · fix the typo · squash the bugs · don't deploy on Friday · decline the meetings · stop at the last index · catch the exceptions · merge when it's green · pick a good name · find the root cause

Every four jobs, everything speeds up. Four mistakes and you burn out. The share button copies your run as a row of green and red squares.

Each job is one object in the `JOBS` array: a `setup(c)` that builds its UI and calls `c.win()` or `c.lose()`. Adding a sixteenth is about 30 lines.

One HTML file, no dependencies. Written with Claude Code and published with [Vesta](../../README.md). `?demo` plays itself.
